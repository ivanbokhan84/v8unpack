Что это

Обёртки, а не новый распаковщик

Пакет v8unpack 1.2.13 не изменён. Исправления и ускорения — модули в vanteam/tools, они подменяют методы v8unpack во время запуска. Каждое ускорение выключается переменной V8UNPACK_DISABLE, результат при любом наборе одинаковый.

Замер

Что даёт каждое ускорение

Расширение 3 МБ, пять раундов с чередованием, CPU процесса. В каждом варианте выключено ровно одно ускорение. Машина была загружена чужими процессами, поэтому сравнение идёт по CPU, а не по времени по часам. Дерево результата во всех 35 прогонах одно и то же.

Запуск

Три команды

Python 3.11, pip install v8unpack==1.2.13; psutil нужен только для продолжения после обрыва. Не передавайте --descent: это номер версии для инкрементальной сборки, а не глубина.

python vanteam/tools/check_cf.py "файл.cf"
python vanteam/tools/run_unpack.py "файл.cf" "каталог_результата" "каталог_temp"
python vanteam/tools/v8unpack_serial.py "файл.cfe" "каталог_результата"

rem выключить отдельные ускорения, результат тот же
set V8UNPACK_DISABLE=fastbrace,inplace
