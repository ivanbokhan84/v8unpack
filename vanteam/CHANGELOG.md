# Журнал изменений

Версии обёрток v8unpack-accel. Пакет v8unpack не меняется; проверено на v8unpack 1.2.13 (и 1.2.6 для 1.0.0),
Python 3.11, Windows 11. Поставки — `releases/v8unpack-accel/<версия>/`, рабочая копия — `tools/`.

## 2.0.0 — 29.09.2026

Все найденные ускорения распаковки. Выход побайтно тот же, что у 1.0.0 и штатного v8unpack.
Каждое ускорение — отдельный модуль; любое выключается переменной окружения `V8UNPACK_DISABLE`.

Добавлено:
- `v8unpack_accum.py` — квадратичные склейки строк: base64 в формах, текстовые файлы, многострочные значения,
  раскладка модулей по областям (`OrganizerCode.unpack`: модуль 3,2 МБ — 30 с → 0,08 с).
- `v8unpack_fastbrace.py` — разбор скобочного формата через `json.loads`: текст переводится в JSON операциями
  уровня C, необычные файлы уходят в исходный автомат.
- `v8unpack_jsonwrite.py` — запись JSON своим сериализатором одной строкой (формат побайтно как у `json.dump`).
- `v8unpack_io.py` — вложенные контейнеры распаковываются в памяти (нет `os.rename` сразу после записи —
  источника WinError 32), кэш созданных каталогов.
- `v8unpack_organizer.py` — организатор без копирования: `decode_stage_3` переносится в результат одним
  переименованием; неизменённые модули и формы не перезаписываются.

Изменено:
- `v8unpack_fastparse.py` — значения вне кавычек (числа, UUID) берутся куском, а не по символу; в шапке указан
  источник кода (MIT, v8unpack).
- `v8unpack_serial.py` — версия, подключение ускорений, `V8UNPACK_DISABLE`, строка версии в выводе.
- `v8unpack_fastparse_check.py` — эталон теперь исходный `JsonContainerDecoder` (с толерантным `decode_file`),
  проверяется вся цепочка ускорений разбора; обход каталога рекурсивный; код возврата 1 при расхождениях.
- `run_unpack.py`, `v8unpack_resume.py` — строка версии в выводе; пути в примере запуска заменены плейсхолдерами.

Приёмка, замеры и отчёты — `releases/v8unpack-accel/v2.0.0/README.md`, `evidence/`, HTML-отчёт о замерах и статья.

## 1.0.0 — 28.09.2026

Первая поставка, выделена из рабочих проектов 1С (копии `tools\` в 33 проектах побайтно совпадают).

- `v8unpack_serial.py` — серийный пул вместо multiprocessing (гонки WinError 32/5/87), ретраи `os.replace`/`os.remove`,
  толерантный `decode_file` (ошибка `READ_TEXT_FILE` в v8unpack), пониженный приоритет процесса.
- `v8unpack_fastparse.py` — квадратичное накопление длинных строк в разборщике: форма 1,9 МБ — 385 с → 0,34 с.
- `v8unpack_newtypes.py` — вид метаданных `PaletteColor` (платформа 8.5.1).
- `v8unpack_resume.py` — продолжение с третьего прохода по готовому `decode_stage_1`.
- `run_unpack.py` — лаунчер для крупных `.cf`: TEMP на другой диск до импорта v8unpack.
- `check_cf.py` — проверка целостности контейнера. `v8unpack_fastparse_check.py` — сверка разборщика.
