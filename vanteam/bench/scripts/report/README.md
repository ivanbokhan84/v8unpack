# Сборка HTML-отчёта и доказательств 2.0.0

- `gen_html.py <summary.json> report_body.html style.css <Отчёт_замеров_v8unpack.html> <Оптимизация_распаковки_v8unpack.html>` —
  числовые разделы отчёта (плитки, таблицы и графики .cfe) и раздел 4 статьи из `summary.json` парного замера
  (`bench_pair.py`). Повторный запуск даёт тот же файл: блоки заменяются по границам разделов.
- `report_body.html` — шаблон отчёта (текст разделов, заглушки `<!--TILES-->`, `<!--CFE-->`, `<!--ABL-->`, `<!--ACCEPT_CFE-->`).
- `style.css` — стили статьи (тот же вид у обеих страниц).
