# v8unpack-accel 1.0.0

Дата: 28.09.2026. Базовая поставка: инструменты в том виде, в каком их копии лежат в `tools\` рабочих проектов 1С
(33 проекта, md5 всех 7 файлов совпадают, сверено 29.09.2026). От неё отсчитываются патчи 2.0.0.

## Состав `tools/`

| Файл | Назначение |
|---|---|
| `v8unpack_serial.py` | серийный пул вместо multiprocessing, ретраи WinError 32/5, толерантный `decode_file`, пониженный приоритет; подключает fastparse и newtypes |
| `v8unpack_fastparse.py` | квадратичное накопление длинных строк в `JsonContainerDecoder`: форма 1,9 МБ — 385 с → 0,34 с |
| `v8unpack_fastparse_check.py` | сверка ускоренного разборщика с исходным на файлах `decode_stage_1` |
| `v8unpack_newtypes.py` | вид метаданных `PaletteColor` (платформа 8.5.1) |
| `v8unpack_resume.py` | продолжение с третьего прохода по готовому `decode_stage_1` (нужен `psutil`) |
| `run_unpack.py` | лаунчер для крупных `.cf`: TEMP на другой диск до импорта v8unpack |
| `check_cf.py` | проверка целостности контейнера |

## Цифры

Контрольный замер 28.09, `.cfe` 3 МБ → 1483 файла, против штатного `v8unpack -E`:
CPU −30% (33,5 → 23,5 с), память −84% (218 → 36 МБ), выход побайтно тот же.
Реальные прогоны: УТ 11.5.27.93 (883 МБ) — 46,5 мин, 68 177 файлов; третий проход УНФ 3.0.14 — 17 мин 47 с.

(`run_unpack.py`) и ссылка на внутренний гайд (`v8unpack_serial.py`). Код не менялся; патчи 2.0.0 и манифесты
